MQMCorp HTML WEBSITE

1. Extract the ZIP file.
2. Double-click index.html to open it in Edge or Chrome.
3. To change the content, right-click index.html and open with Notepad or VS Code.
4. Search for YOUR_BUSINESS_EMAIL@example.com and replace it with your actual email address before publishing. The contact form prepares an email; it does not send messages by itself.
5. Upload index.html to a static hosting service when you want a public website.

No React, Node.js, npm or installation required.
